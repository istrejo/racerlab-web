# RacerLab Web Claude Instructions

Follow `../AGENTS.md` in this repository as the primary instruction source.

Critical reminders:

- This is the Angular frontend only.
- Use Angular 22+, TypeScript, standalone components, signals, Signal Forms or Reactive Forms, Angular Router, guards, services, and functional interceptors.
- Style with Tailwind CSS; use PrimeNG or custom UI only when useful and accessible.
- Consume the NestJS REST API through `API_URL`.
- Do not connect Angular directly to Supabase for business operations.
- Keep models and enums aligned with the backend OpenAPI/Swagger contract.
- Preserve WCAG AA and AXE accessibility requirements.
