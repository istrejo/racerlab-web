# RacerLab Web Gemini Instructions

Follow `../AGENTS.md` as the primary project instruction source.

- Build the Angular frontend with TypeScript, standalone components, signals, Signal Forms or Reactive Forms, Angular Router, guards, services, and functional HTTP interceptors.
- Use Tailwind CSS; PrimeNG or custom UI is optional when it improves delivery and accessibility.
- Keep feature boundaries under dashboard, customers, vehicles, service-orders, quotes, inventory, technicians, reports, and settings.
- Consume only the NestJS REST API through `API_URL` for business operations.
- Do not connect directly to Supabase from the frontend for business operations.
- Align models and enums with OpenAPI/Swagger from the backend.
- Preserve AXE and WCAG AA accessibility requirements.
